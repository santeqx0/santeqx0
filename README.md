## ⚡ About

I build things for the web — most of my time goes into **TypeScript, React and Node.js**, from the interface down to the API behind it.

Away from the browser I write **Discord bots, FiveM resources and Roblox scripts**, mostly because I wanted something that didn't exist yet. I'd rather ship something small and finished than plan something big.
